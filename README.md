# Calendario de reservas — Nacho Ibáñez (kitesurf)

Calendario de reservas self-hosted para clases de kitesurf, basado en
[cal.diy](https://github.com/calcom/cal.diy), desplegado en Hetzner detrás de un
Cloudflare Tunnel + Cloudflare Access.

Ver el diseño completo en [`docs/booking-design.md`](docs/booking-design.md).
